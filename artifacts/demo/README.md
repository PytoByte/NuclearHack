# Материалы демонстрации

- Видеодемонстрация работы приложения: добавьте файл `demo.mp4` (или ссылку на него)
  в этот каталог. Файл не обязателен в Git из-за размера; можно хранить его как
  release asset.
- Демонстрация должна показывать: импорт аудиофайла, фоновую транскрибацию с
  уведомлением, открытие расшифровки из списка недавних/всех записей,
  экспорт результата в JSON.
