# Решения

## exp_0001 — ограниченная память декодера

Гипотеза: потоковый native MP3 decoder не накапливает полный PCM при увеличении
длительности. Метод: по одному процессу на синтетических stereo MP3 10/600 секунд,
48→16 kHz mono, callback блок 16000 float samples, Linux wait4 peak RSS.
Результаты: 13092/13116 KiB RSS, 0.0276/1.6489 секунды decode wall time.
Решение: сохранить как начальный decoder. Статус screening **inconclusive** для
общего утверждения о памяти/качестве: один синтетический сигнал не охватывает
форматы, повреждённые файлы и качество речи. Не относится к Android inference.
Следующий эксперимент: размеченные русские диалоги, реальный GigaAM CTC,
INT8/FP32/threads и фиксированная нормализация WER.
